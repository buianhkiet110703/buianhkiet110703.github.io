A one-page portfolio (English / Vietnamese) for Data Analyst, Analytics Engineer and BI roles.

## Files

| File | What it is |
|---|---|
| `index.html` | The whole site: layout, styles, text and script |
| `Anh_Kiet_Bui_Resume.pdf` | The CV behind the "Download CV" buttons |
| `portrait.webp` | Profile photo |
| `award_stage.webp`, `certificate.webp`, `trophy.webp` | Award section pictures |

| `risk_segments.webp`, `risk_ext.webp` | Credit risk charts |

## How to edit

All the text lives near the top of the `<script>` in `index.html`, in plain lists:

- `T` – headings, intro and button labels, in `en` and `vi`
- `FACTS` – the four big numbers in About
- `JOBS` – work experience and education
- `SKILLS` – skill groups
- `PROJ` – projects (title, description, numbers, bullets, GitHub links)
- `CERTS` – certificates and their links

To change something on GitHub: open `index.html` → pencil icon → edit → **Commit changes**.
The site updates by itself about a minute later.

To replace the CV: upload a new file with the same name, `Anh_Kiet_Bui_Resume.pdf`.
